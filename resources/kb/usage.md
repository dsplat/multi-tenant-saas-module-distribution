# 分销模块使用手册

## 模块简介
本模块为 SaaS 平台提供完整的分销裂变与分润结算能力，旨在帮助运营人员搭建多级分销体系、管理分销员队伍、自动化处理佣金计算与提现打款流程。通过该模块，企业可实现客户归因绑定、团队层级管理、灵活佣金规则配置及资金流水透明化，有效降低人工核算成本，提升推广转化效率。

## 核心功能

### 分销员全生命周期管理
支持分销员的申请接入、资质审核、状态管控与信息查询。运营人员可在控制台查看分销员列表及其上下级树状结构，对单个分销员进行详情查阅、冻结或解冻操作。系统维护分销员档案，涵盖基础信息、邀请码、累计佣金、可提现余额、冻结余额及当前状态等核心字段。

### 佣金规则引擎
提供可视化的佣金策略配置能力。运营人员可创建、编辑、删除或停用不同层级的计佣规则。规则支持按固定金额、比例抽成等方式设定，并可配置适用范围、优先级、单笔最低/最高限额等条件。系统底层通过佣金匹配服务自动识别订单适用的计佣规则，确保分润逻辑准确执行。

### 团队关系与业绩归因
基于邀请链接或专属二维码实现客户自动归因绑定。系统维护分销关系链数据，支持查询买家归属的分销员、获取上级分销员链条（用于多级计佣）以及查看直接下级与间接下级组成的团队树。当订单支付成功时，佣金计算引擎会自动触发流水创建与冻结入账；若发生退款，系统将自动执行佣金冲销。

### 提现审批与资金打款
提供从分销员发起提现到财务确认到账的完整闭环。分销员端可查看账本流水并提交提现申请；运营人员在后台接收提现单后，支持按状态筛选列表，执行通过、驳回或人工确认已打款操作。系统对接打款驱动解析器，支持多渠道配置与打款记录追踪，确保资金流向可查可控。

### AI 辅助分析
内置分销模块 AI 增强服务，提供异常行为检测与分润收益分析建议。该功能仅作为只读参考，帮助运营人员快速定位潜在风险并优化分润策略。

## 常见操作流程

### 配置分销基础参数
1. 进入控制台「分销管理」页面，访问分销系统配置接口路径。
2. 根据业务需求设置全局开关、最大分销层级、自购返利比例、审核模式、结算周期天数、锁定期天数、最低提现金额及提现手续费率等参数。
3. 保存配置后，系统将立即生效，新产生的订单与提现请求将遵循新规则流转。

### 审核分销员申请
1. 在控制台分销员列表页查看待审核的申请记录。
2. 点击目标分销员查看详情，核对身份信息及邀请来源。
3. 调用状态更新接口，选择“通过”或“驳回”。若驳回，需填写审核备注以便反馈给申请人。
4. 审核通过后，该用户正式获得分销资格，其邀请链接与海报生成权限同步开通。

### 处理提现申请
1. 进入后台提现管理列表，按“待审核”状态筛选提现单。
2. 核对提现金额、收款账户信息及历史账本流水，确认无误后执行“批准”操作。
3. 打款完成后，在对应提现单上执行“确认已打款”标记；若打款失败或需退回，执行“拒绝”操作，系统将自动触发账本余额返还。
4. 所有审批动作均会沉淀至提现记录表，支持后续分页追溯。

### 查看佣金与账本流水
1. 运营人员可通过分销员详情页或独立流水查询入口，调取指定分销员的佣金明细。
2. 系统按订单类型、层级、金额、规则 ID 及状态分类展示佣金记录。
3. 账本流水涵盖冻结、结算、冲销、提现扣减、人工调整等全量资金变动，支持按关联类型与时间范围分页检索。

## 相关配置说明

### 全局分销配置
位于控制台分销配置路由下，主要包含以下控制项：
- `enabled`：控制分销模块整体启用状态。
- `max_level`：定义分销裂变的最大层级深度。
- `self_buy_rebate`：设置分销员自购订单的返利比例。
- `audit_mode`：决定分销员加入是否需要人工审核。
- `settle_days` 与 `lock_days`：分别定义佣金结算周期与资金锁定保护期。
- `withdraw_min_amount` 与 `withdraw_fee_rate`：设定提现门槛金额及手续费计算基准。

### 打款渠道配置
独立于分销主配置，用于管理资金下发通道。运营人员需在打款配置路由下录入渠道标识、商户号、序列号、私钥及 APIv3 密钥等安全凭证，并维护渠道状态。配置生效后，提现审批通过的单据将自动路由至对应驱动执行打款任务。

### 佣金规则配置
规则配置路由支持多维度策略管理。每条规则需明确名称、适用层级、计算类型（比例或固定金额）、费率或固定值、适用范围及范围配置参数。系统依据优先级自动匹配最优规则，规则停用后将不再参与新订单的佣金计算，历史已结算记录不受影响。
